# 차근 (chageun)

**비개발자가 안전하게 만들도록 돕는 워크플로우** — 작업카드·검증 게이트·실제 구동 검증·쉬운 말 요약. Claude Code에서 동작합니다.

---

## 무엇을 해주나

기획이 약하면 원하던 것과 다른 게 나오고, 검증이 약하면 무한 디버깅 지옥에 갇힙니다. 차근은 **기획 → 게이트 → 구현 → 실제 구동 검증 → 마무리** 흐름으로 그 두 함정을 막아줍니다.

코드는 Claude가, 설명은 쉬운 말로, 판단은 당신이.

---

## 차근의 자리 (2026)

AI 개발의 무게중심은 **프롬프트 → 하네스 → 루프 엔지니어링**으로 옮겨가는 중입니다(Karpathy의 AutoResearch가 대표적 — 프롬프트를 일일이 쓰는 대신 스스로 도는 루프를 설계하자는 흐름). "좋은 지시문 한 줄"에서 "스스로 돌고 검증하는 시스템"으로의 이동입니다.

**카파시는 왜 자신을 루프에서 지웠나.** 그의 관찰은 — 병목은 컴퓨트가 아니라 사람이라는 것입니다. 검증이 자동화·신뢰 가능하고(예: 학습 손실) 되돌리기가 값쌀 때, 사람이 단계마다 결과를 들여다보는 건 정확성을 더하지 못하고 속도만 깎습니다. 그래서 "조건을 세팅하고 물러나는 것"이 최고 레버리지가 됩니다. 단 그조차 "사람을 없앤다"가 아니라 *잡일에서 해방해 창의·판단에 집중*시키는 것입니다.

**그런데 차근은 이 방법론을 절반만 따릅니다.** 카파시의 자율 루프에는 숨은 전제 두 가지가 있습니다 — ① 신뢰할 수 있는 자동 검증 지표 ② 값싼 되돌리기. 비개발자가 만드는 실제 제품엔 둘 다 없습니다: "잘 됐나"를 담을 단일 숫자가 없고, 행동(운영 쓰기·결제·삭제)은 되돌리기 비쌉니다. 게다가 검증을 사람이 떠나면 *의도부채*(왜 이렇게 만들었는지 맥락 유실)가 쌓이고, 비개발자는 자기 분야 밖의 '그럴듯한 가짜'를 걸러내기 어렵습니다.

그래서 차근은 이미 **하네스**이되(매 세션 워크플로우 자동 주입·게이트·검증), 목적함수가 다릅니다:

- **자율 루프**(카파시류): 사람을 루프 밖으로 빼 처리량을 키운다.
- **안전 하네스**(차근): 사람을 *위험 지점에* 남긴다 — 비개발자가 코드를 못 읽어도 안전하게.

차근의 자리는 **"AI는 깊게, 사람은 중요한 데만"**입니다. 위험 없는 작은 일은 가볍게(LIGHT) 흐르고, 위험하거나 애매하면 무겁게(FULL) 가되 — 삭제·배포·운영 쓰기 같은 브레이크는 어떤 경우에도 그대로입니다.

---

## 하네스를 직접 짜지 않아도 됩니다

AI로 뭔가를 만든다는 건 점점 "좋은 프롬프트 쓰기"가 아니라 **하네스를 설계하기**가 되고 있습니다. 하네스는 모델을 감싼 뼈대예요 — 어떤 도구를 쓰고, 어디서 멈추고, 무엇을 검증하며, 어떤 순서로 흐르는지. 좋은 결과는 "지시문 한 줄"이 아니라 이 뼈대에서 나옵니다.

그런데 이 뼈대를 비개발자가 직접 엔지니어링하기는 어렵습니다. 차근은 그 뼈대를 **비개발자용으로 미리 설계해 건네는 하네스**입니다. 다 숨겨버리고 "알아서 만들어드릴게요"가 아니라 — 검증 게이트·제품 지도·디자인 시스템·쉬운 말 설명을 **열린 층으로** 얹습니다.

- **직접 짜지 않아도 됩니다** — 설계된 뼈대를 그대로 씁니다.
- **숨겨져 있지 않습니다** — 무엇이 왜 일어나는지 쉬운 말로 보입니다.
- **갇히지 않습니다** — 열린 하네스(Claude Code) 위에 얹혀, 만든 것이 그대로 이식됩니다.

## 설치

```
/plugin marketplace add chacheum/chageun
/plugin install chageun
```

새 세션이 시작되면 워크플로우가 자동으로 켜집니다.

### 알아 두실 것: 안 쓰는 개발 서버를 정리합니다 (Linux · WSL)

세션이 **시작될 때** 한 번, 방치된 개발 서버(`next dev` · `vite` 등)에 종료 신호를 보냅니다. 메모리를 크게 잡아먹기 때문입니다. 끄는 조건은 둘 중 하나입니다.

1. 그 서버의 작업 폴더가 **지워졌다**
2. **셋 다** 참이다 — 붙어 있는 접속이 없다 · 그 폴더를 열고 있는 Claude 세션이 없다 · **켜진 지** 2시간이 넘었다

**끄고 싶으면 `CHAGEUN_SKIP_REAP=1` 로 세션을 시작하십시오.** 아무것도 건드리지 않습니다. 더 보수적으로만 하고 싶으면 `CHAGEUN_REAP_MIN_AGE_MS` 로 시간 문턱을 **올리세요**(예: 6시간 = `21600000`). 특정 폴더 아래만 정리하려면 `CHAGEUN_REAP_ONLY_UNDER=/home/나/projects` 처럼 폴더를 지정하세요 — 그 아래 것만 봅니다.

> ⚠ **터미널에서 직접 켠 개발 서버는 "주인 없음"으로 봅니다.** Claude가 켠 것만 주인이 있다고 판단하기 때문입니다. 또 "접속 없음"은 그 순간의 사진이라, 노트북이 절전에서 깨어나 연결만 끊긴 서버(브라우저 탭은 그대로 열려 있음)도 방치로 읽힐 수 있습니다. 끄기 전에 2초 뒤 한 번 더 확인하지만, 그동안 다시 붙지 않으면 종료됩니다. 개발 서버를 손으로 띄워 두고 오래 쓰신다면 위 스위치를 켜 두십시오.

## 개발 / 기여

정본(소스)은 `src/`에 있습니다.

```bash
npm run build   # src/ → dist/claude 생성 (결과물은 커밋 대상)
npm test        # 골든·드리프트 가드 (--test-concurrency=1)
```

`dist/`는 빌드 산출물이지만 **레포에 커밋**합니다 — 마켓플레이스가 소스를 직접 참조하기 때문입니다.

설계·계획 문서는 로컬 `docs/`에 두며 `.gitignore`로 제외됩니다.
